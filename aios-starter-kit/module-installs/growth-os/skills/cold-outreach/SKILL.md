# Cold Outreach

Write a cold message a real person would actually reply to — specific, human, and about *them*, not a pitch. The output is the ready-to-send message, not advice about outreach.

## Gather (fast, don't interrogate)

1. **Who + why** — the recipient (name/role/company) and what the user wants from them. If a name or company is given, and a web/search connector is available, pull one real, specific detail about them (a recent post, launch, role change) to anchor the opener.
2. **The user's angle** — what the user does and the single relevant reason this person should care (from `context/*.md`).
3. **Channel** — email or DM (DMs are shorter). Default email if unclear.

## Output shape

```
Subject: <4-6 words, specific, no clickbait>   (email only)

<Opener: one line that proves you actually know who they are — a real detail, not "I came across your profile">
<One line: the relevant reason you're reaching out — their problem or goal, in their terms>
<One line: the specific, low-friction ask — a question or a 15-min chat, never "let me show you our platform">
<Sign-off>
```

## Rules (anti-AI-slop)

- **Under 90 words.** A cold message that scrolls is deleted.
- **Lead with them, not you.** The first sentence must be about the recipient. If you can't say something specific about them, say so and ask the user for one detail rather than inventing it.
- **One ask, low-friction.** A question they can answer in one line beats "book a demo."
- **No buzzwords, no "I hope this finds you well", no fake flattery, no em-dashes-as-drama.** Plain, direct, like a smart human wrote it in 2 minutes.
- **Never invent facts** about the recipient. If unverified, keep it general and flag what to personalize.

## After drafting

Offer to: produce 2 subject-line variants, adapt for DM vs email, or — if a mail connector is set up and the user confirms — send it. Never send without explicit confirmation.
